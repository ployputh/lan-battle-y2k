LAN BATTLE Y2K — 50 ข้อ / 30 คน

เผยแพร่เว็บโดยไม่ต้องเปิด CMD เอง:
1. เข้า github.com สมัครบัญชีและสร้าง New repository ชื่อ lan-battle-y2k
2. Add file > Upload files แล้วอัปโหลด index.html, server.js, questions.json, package.json, render.yaml จาก ZIP ที่แตกแล้ว
3. Commit changes
4. เข้า dashboard.render.com แล้วเลือก New > Web Service เชื่อม GitHub repository
5. ตั้ง Build Command: npm install และ Start Command: npm start เลือกแพ็กเกจที่ต้องการ แล้ว Deploy
6. รอจน Live และคัดลอกลิงก์ https://...onrender.com ส่งให้นักเรียน
7. ครูเข้าลิงก์ กดสร้างห้อง รับ PIN 6 หลัก นักเรียน 30 คนเปิดลิงก์เดียวกันและใส่ PIN
8. ครูกดเริ่มการแข่งขัน 50 ข้อ

สำคัญ: ยังไม่ได้เผยแพร่เป็นเว็บไซต์จริง ขั้นตอนข้างต้นต้องทำด้วยบัญชีของครู
โฮสติ้งฟรีอาจพักระบบเมื่อไม่มีผู้ใช้ และห้อง/คะแนนในเวอร์ชันนี้เก็บใน RAM จึงหายเมื่อระบบรีสตาร์ตหรือพักระบบ
แนะนำทดสอบกับโทรศัพท์ 2-3 เครื่องก่อนใช้งานจริง และเลือกโฮสติ้งแบบไม่พักระบบหากต้องการความต่อเนื่อง
